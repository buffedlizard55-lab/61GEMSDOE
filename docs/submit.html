Step 2 — open the submission page

https://www.drivendata.org/competitions/306/competition-doe-gems/submissions/

You must be logged in. The data and submission tabs require an account.

Step 3 — choose the file, paste the note

The form asks for a "File to submit" and an optional "Note". Paste exactly this into the Note field (122 of the 140 allowed characters):

Parker-Oldenburg inversion of isostatic gravity; 3-px catalogue-excluded HGM maxima of basement relief, binary all-finite.

Then press submit.

Step 4 — read the receipt

The page returns a score. That number, on that page, is an organizer receipt and is the only kind of score this project will report as confirmed. Every other score you will see in the group's repositories is a claim. See Evidence for why that distinction is enforced here.
