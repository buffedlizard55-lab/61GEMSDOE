Why this is a hard stop

All 748 aligned rasters in the accessible sibling-repository registry were checked (this registry excludes 61GEMSDOE's historical TIFFs and private/inaccessible submissions). The continuous-surface gate passed (worst Spearman rho 0.030846), but the final-dot gate failed: 70 registry entries exceeded the strict 70% overlap threshold and the maximum three-pixel overlap was 100%. The implementation stopped rather than altering dots after seeing this result. This is the required fail-closed behavior; it is not a finding that any file was copied.

Archived files are not current candidates

The repository retains historical TIF/ZIP outputs under docs/downloads/ and docs/submissions/ for traceability. They are not H61U artifacts, are not linked as downloads here, and are not recommended for the current submission. A one-click link will be added only after a new, properly registered run creates a distinct raster and all format and uniqueness checks pass.
