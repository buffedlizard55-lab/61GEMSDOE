Submit in four steps

  1. Download the GeoTIFF from the panel at the top of this page (or docs/submissions/<name>.tif in the repository). It is a single-band float32 GeoTIFF, 3730 × 3292, EPSG:32611, 100 m cells, values 0/1 with 0 outside the scored footprint.
  2. Open the competition submissions page (sign-in required) and press New submission.
  3. Choose the file in File to submit. You may submit the .tif directly, or the .zip that contains the same single GeoTIFF.
  4. Paste the note below into the optional Note field so the row is identifiable later, then create the submission.

Three rules from the official rules PDF that constrain this step: (i) at most three submissions per week; (ii) one submission must be selected as the final one for both prize rounds, and it must be selected without knowledge of the private-test score; (iii) if generative AI was used to develop the submission, that use must be disclosed in the submission narrative. This lane's artifacts were produced by an autonomous agent, so the disclosure applies — see the note below.
