How to make a submission, exactly

Two minutes, start to finish. Download the GeoTIFF at the top of the home page, then paste the name and the note into the submission dialog. Nothing else is needed.

1 · Download

On the home page, click Download the GeoTIFF. The file is gems61-h61a-basement-step-20000dots-20261011T012029Z-eb2ae4bb024b-zeros.tif. If the portal prefers a ZIP, use Single-TIFF ZIP instead — it contains exactly one GeoTIFF and nothing else. Do not upload the JSON run card, this page, or a ZIP of the repository.

2 · Check it is the file you think it is (optional, 10 seconds)

Re-hash it. On macOS/Linux: shasum -a 256 gems61-h61a-basement-step-20000dots-20261011T012029Z-eb2ae4bb024b-zeros.tif — it must print

4 · What happens next, and what does not

  • Uploading spends one of the three weekly submission slots. This repository has not spent one. Promotion to a slot is your decision.
  • When a score comes back, write it down with the date. That number, and only that number, is a competition score; everything on this site is labelled MEASURED, HOLDOUT-DTI or OWNER-REPORTED and none of those is a score.
  • If the portal rejects the file, capture the exact error text and add it to evidence/ — a rejection is evidence, and the range error reported against an earlier site's download is the reason every value here is checked to be finite and inside [0, 1] before the file is written.

Why the file is shaped the way it is

The competition metric is DTI = TP_w / (TP_w + 0.2·FP_w + 0.8·FN_w) with a triangular kernel of radius 300 m, and the mapped-fault catalogue is masked out of scoring. Two consequences decide the shape of this file: a dot on a mapped trace earns nothing (the pixel is not scored), and a dot only pays if it lands within about 280 m of a hidden truth pixel at the scores currently on the board. That is why the dots sit in a band a few pixels off the mapped traces rather than on them, and why they are dots and ribbons rather than a smooth probability surface.
