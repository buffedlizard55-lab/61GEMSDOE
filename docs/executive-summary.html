Bottom line: H61U-H1 did not clear final-dot uniqueness. No candidate GeoTIFF, ZIP, submission receipt, or artifact-linked organizer score was produced. Download permission is NO; submission is not recommended; weekly-slot approval is false.

What was tested

The frozen H61U-H1 hypothesis inverted band-13 isostatic gravity using an explicitly uncalibrated Parker–Oldenburg first slab iterate, located maxima of the horizontal gradient of basement depth, and tested signed depth contrast at 2 km and 4 km on opposing flanks. It retained same-sign steps above a 0.60 persistence ratio and proposed 3-pixel multi-line ribbons. GP-1012 was reserved only for calibration and was not locally available in full. Organizer band 15 was not used as a feature or calibration target.

What the local holdout says

HOLDOUT-DTI · gems61-pooled-hide-v2 · 12,074 withheld positives: H61U-H1 scored 0.041351 (95% CI 0.035332–0.048100), compared with unfiltered HGM maxima at 0.044359 (0.036847–0.051764) and matched random lines at 0.016030 (0.010328–0.021541). H61U-H1's paired difference versus HGM was -0.003009 (95% CI -0.010105–0.004951); the experiment therefore did not show a gain over the strongest simple control. It did outperform random lines. The withheld-segment recovery was 128/318 (40.25%, Wilson 95% CI 35.01%–45.73%), compared with 138/318 (43.40%) for HGM and 40/318 (12.58%) for random lines.

These are local, spatially blocked catalogue-holdout metrics—not public leaderboard scores, not organizer-confirmed results, and not direct estimates of recovery for undisclosed new faults.

Why the run stopped

The continuous pre-placement surface passed the complete accessible sibling-registry test: 748 rasters, maximum Spearman rho 0.030846, below the 0.90 stop limit. The inventory excludes this repository's historical TIFFs and private/inaccessible submissions. The independent final-dot test failed: 70 registry entries crossed the >70% three-pixel overlap threshold; maximum overlap was 1.0. Under the registered rule, this must stop promotion and file writing. No overlap-based pruning or parameter tuning was attempted after seeing the gate result.

Non-fault mimic and leakage checks

The registered synthetic finite intrabasement density sheet had no basement relief. It produced 21,252 HGM maxima, of which 172 survived the same-sign persistence filter (0.81% retention). It is a named mechanism control, not a DTI result. All six single-feature leakage canaries had AUC ≤0.555204, far below the 0.90 blocker; this only addresses the tested leakage pattern.

Decision in plain language

  • Is there a H61U TIF to download? No. The uniqueness stop occurred before a new file was written.
  • Is it okay to download an old TIF from this repository as the H61U result? No. Older files are historical artifacts from other runs and are not the current candidate.
  • Should H61U-H1 be submitted? No; it failed the strict uniqueness gate and did not beat the unfiltered HGM holdout control.
  • Is a weekly slot approved? No. Slot choice is a separate selector decision.
  • Is there an organizer score? No artifact-linked receipt exists.

For exact values and the registry receipt, use the run card. See remaining work for GP-1012 access, attribution limits and a responsible follow-up process.
