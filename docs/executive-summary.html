What This Submission Does

Method: Parker/Oldenburg gravity inversion → basement depth → horizontal gradient maxima (steps) → ±1 km corridor → find magnetic (TMI) edges within corridor → emit 3-pixel-wide ribbons

Why it works: Gravity identifies basement steps (potential buried faults) at ~1 km resolution. Magnetic data detects edges where faults offset magnetized basement or volcanic flows at higher resolution. The conjunction filters out density contrasts within basement (which have no magnetic expression).

Competing explanation: Density contrasts within basement create gravity steps without faults. These lack co-located magnetic edges, so the conjunction filters them out.

Technical Details

  • Gravity band: 13 (isostatic residual gravity)
  • Magnetic band: 3 (Total Magnetic Intensity - TMI)
  • Inversion: Parker/Oldenburg first iterate (slab solution) with GP-1012 calibration
  • Density contrast: -300 kg/m³
  • Reference level: 500 m
  • Filter: Butterworth order 4.0, kc = 2.500×10⁻⁴ rad/m

  • Ribbon width: 3 pixels (300 m)
