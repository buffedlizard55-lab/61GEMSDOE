Irregularities and limitations

IDSummaryImpactStatus
IR-1blockerThe prescribed calibration reference (GP-1012) is not obtainable from this sandbox
The lane prescribes the USGS Basin and Range basin-depth maps of Saltus & Jachens (1995), GP-1012, 1:2,500,000, to calibrate the density-contrast depth scale. The product page confirms the map is real and is sold as a paper, folded map only: no digital raster is published there. The USGS Store and the pubs.usgs.gov data endpoints are outside this sandbox's egress allowance, so the map could not be retrieved.
Substitution: Band 15 depth_to_base_surf (the organiser's own derived depth-to-basement product) is used as the depth-scale reference instead.		Band 15 descends from the same gravity/ drill-hole inversion tradition as the map, so calibrating to it is partially circular: it fixes the metres-per-mGal scale but cannot independently validate either depth or position. Every depth number in this lane inherits that caveat.open - permanent for this session
IR-2majorA linear Bouguer slab beats every iterative inversion against the depth reference
Across a 48-point grid over density contrast (300-650 kg/m3), reference depth (1000-3000 m) and taper cutoff (2000-5000 m), the best iterative Parker-Oldenburg field reaches Pearson 0.6575 against band 15. The trivial linear estimate depth = -g / (2*pi*G*400) reaches Pearson 0.7318 with a lower RMSE (220.7 m vs 286.5 m).		The iterative inversion is retained because its regression slope against the reference is 0.958 (near unit, i.e. an unbiased scale) while the slab's is 0.540 (a systematic ~2x compression). The two criteria disagree, and the disagreement is not resolved by any measurement available here. The depth scale is reported with a factor-of-two systematic band attached.open - documented, not resolved
IR-3majorThe measured positional resolution is three times the metric's kernel radius
Distance from catalogue pixels to the nearest detected step crest: p10 = 2.0 px, p50 = 9.0 px, p90 = 19.2 px (200 m / 900 m / 1900 m at the 100 m grid). The competition metric credits a prediction only inside a 300 m (3 px) triangular kernel.		Most emitted cells fall outside the kernel entirely. This is a physical limit of potential-field inversion, not a code defect, and it is the single largest term in the lane's error budget. It is why the wide-ribbon arms exist and why none of them recovers the loss.open - physical, irreducible without new data
IR-4minorThe sibling repository's data/official/labels.tif is byte-identical to existing_faults.tif
Both files are 425,830 bytes with SHA-256 7ba308cc... .		It must not be described as an independent official label set. This lane's holdout is built from the mapped-fault catalogue only, and the two names are treated as the same raster throughout.documented
IR-5minorNo leaderboard number in this repository can be ORGANIZER-CONFIRMED
The DrivenData data tab and submission pages are behind a login and no credentials exist in this sandbox. Every score quoted anywhere in this family is OWNER-REPORTED and is labelled as such.		The 0.3195 target and the 0.2778 live reference are owner-reported. Nothing on this site is presented as a contest receipt.documented
IR-6minorThe SE fold carries 262 withheld positives against 2,730-3,347 for NW, NE and SW
The catalogue is not uniformly distributed across the four spatial folds, so one quadrant contributes under 3 % of the withheld truth.		The pooled block bootstrap is effectively driven by three folds. Confidence intervals are reported from the pooled instrument with this asymmetry stated rather than silently averaged away.documented
IR-7resolved3x3 plateau-break thinning deleted 98 % of the step crests
Requiring each crest pixel to be the maximum of its 3x3 neighbourhood reduced the crest from 128,323 px to 2,595 px and cut catalogue-within-3px coverage from 16.5 % to 1.5 %. On the smooth, band-limited depth field produced by this inversion the test destroys along-strike continuity.		Reverted. The test is now opt-in (thin_plateaus=True) and off by default; redundancy is removed by dot thinning, which is the operation the metric actually rewards. A regression test pins the default to False.closed
IR-8resolvedOldenburg's pure cosine taper recovers only a third of the amplitude
With plateau_fraction = 0 the taper attenuates from the lowest wavenumbers and an infinite slab loses most of its response. With plateau_fraction = 0.5 the same slab is reproduced to 0.1 %.		The plateau fraction is fixed at 0.5 everywhere and a test guards against zeroing it.closed

Standing limitations

  • No DrivenData credential: the competition data tab is behind a login, so every input is a hash-pinned public bridge copy. Bridge SHA-256 proves byte identity with that bridge, not official origin.
  • There is no ORGANIZER-CONFIRMED score in this repository. Every number is HOLDOUT-DTI or OWNER-REPORTED.
  • The published labels.tif is byte-identical to existing_faults.tif: the scored truth is not public, so the hide-and-recover holdout is the only local instrument.
  • The holdout truth is the mapped catalogue; the organiser scores faults the catalogue lacks. The instrument is a screen, not a leaderboard estimator.
  • GP-1012, the prescribed depth-scale reference, could not be obtained.
  • Egress is limited to github.com, api.github.com, codeload.github.com, registry.npmjs.org, pypi.org and files.pythonhosted.org.
