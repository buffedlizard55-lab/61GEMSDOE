What this is

One competition lane: buried fault structure from gravity inversion. The provided isostatic-gravity band is inverted for basement relief with the Parker (1973) / Oldenburg (1974) iteration, the result is verified against the competition's own depth-to-basement band, and the maxima of the relief's horizontal gradient are emitted as candidate buried range-front faults.
