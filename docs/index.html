The frame does not merely fail to rank candidates; it ranks them backwards. Instrument study →
  • It is exactly degenerate for catalogue-pruned emission. This file is pruned 2 px from the catalogue, so its minimum dot-to-catalogue distance is 300 m, the kernel radius; every kernel credit is 0 and its holdout DTI is 0.0 by construction. The same prune is what the group's best-reported artifact (0.2778) does. A holdout that returns 0 for the best-known family cannot promote anything.
  • Emission count, not placement, dominates the cross-artifact ranking. ρ = -0.898 (p = 0.0024) for positive-pixel count against the owner-reported live score.
  • The inversion is calibrated. With Δρ = 222 kg/m3 (from the regression of band 13 on band 15, -0.009329 mGal/m, r = -0.621) and z0 = 600 m, the inverted basement depth ranks against the provided depth-to-basement band at Spearman = +0.6949. The parallel session's inversion, at Δρ = −420 kg/m3 and z0 = 1200 m, reports Pearson = −0.1822 against the same band: a sign error. IR-1 →
