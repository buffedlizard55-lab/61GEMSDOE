One-paragraph result

The lane asked for a Parker/Oldenburg inversion of the supplied isostatic-residual gravity, calibrated only against the USGS GP-1012 basin-depth maps, and for the horizontal-gradient maxima of the inverted basement surface as candidate buried range-front and intrabasin faults. We did that, at a 200 m inversion cell instead of the previous session's 400 m (the lane's own statement that "gravity resolves such steps only to a few hundred metres at best" is the reason): 12,572 Blakely-Simpson maxima of |grad depth| → 5,579 steps with a measured throw ≥ 80 m; the inverted surface reproduces GP-1012's >1 km basin fraction (0.198 against the 0.20 anchor), correlates 0.999 with the 400 m solution and 0.745 with the organiser's own depth layer, and anti-correlates with gravity at -0.833 (the sign check). The step field is then used as features in an out-of-fold logistic habitat model over 28 catalogue-independent channels, and the model's ranking places 40,000 binary dots at 3 px spacing, every dot more than 3 px from a mapped trace. Result: HOLDOUT-DTI 0.0606 (CI 0.0494–0.0727) against 0.0314 for random lines and 0.0465 for the previous session's corridor × slope-ridge locator. The analysis page explains why 0.2778 is where it is, and the holdout page shows the leave-one-quadrant-out test that keeps this file off a slot.

What is new this session (H61-M)

  3. The lane's competing explanation is implemented, not asserted. Inverted depth, depth gradient, step throw, step indicator, corridor indicator and an Euler SI = 0 source depth are all model features; their measured logistic weights are small (inv_depth -0.172, inv_depth_hgm -0.204, euler_depth -0.053, step_throw -0.046, step_indicator -0.006, corridor_indicator +0.194). That is the honest negative result for the lane's premise at 300 m.
  4. A leakage finding (IR-61-LEAK-01). A gradient-boosted version of the same model reached HOLDOUT-DTI 0.1670 and a canary AUC of 0.901 — above the protocol's 0.90 line. The leave-one-quadrant-out retest shows the AUC falls to 0.518–0.618 across all 16 blocked retests, with no training pixel inside the scored quadrant: the skill was adjacency to visible traces, not generalisation. The shipped file uses the logistic model, whose canary AUC is 0.626.
