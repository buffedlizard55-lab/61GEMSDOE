Run outcome: H61U-H1's final dots failed the registered uniqueness threshold. No TIF was written; this page documents the frozen method and evaluation, not an available submission artifact.

Input and inversion

  1. Read only training band 13, iso_grav_anom. Aggregate valid 100 m cells to 400 m finite block means for the inversion; use the shared pinned footprint.
  2. Apply the frozen first, low-pass Bouguer-slab iterate of the Parker/Oldenburg interface inversion, with a 1,000 m reference depth, fill-minus-basement density contrast −400 kg/m³, and order-2 stabilizing filter W(k)=1/(1+(k/kc)^2), kc=1/(2z0). H61U does not run the later nonlinear correction iterations. These fixed physical priors were not fitted to the holdout.
  3. Use the resulting basement-depth model to compute horizontal-gradient magnitude. Select local gradient maxima as candidate step crests.

Calibration status: the prior is explicitly uncalibrated. The complete official GP-1012 grid is unavailable locally; no scale calibration is claimed. Organizer band 15 is fail-closed and is not read for calibration, candidate construction, validation, or diagnostics.

Registered physical signature

At each basement-depth HGM maximum, sample the signed depth offset on opposing sides of the local gradient normal at fixed 2 km and 4 km apertures. Retain only centers with the same downthrow polarity at both apertures and persistence ratio min(|Δz₂|,|Δz₄|)/(max(|Δz₂|,|Δz₄|)+ε) ≥ 0.60. This favors a one-sided basement step persisting beyond a narrow density body, rather than gradient amplitude alone.

Registered line/ribbon emission (not written)

The frozen output rule would expand surviving ridge centers to a 3-pixel ribbon on the native grid, thin with a fixed 3-pixel minimum separation, then cap candidate and controls at 40,000 positives. The planned submission dots would be zero on every mapped catalogue pixel and outside the scored footprint, encoded as a binary single-band float32 GeoTIFF matching the supplied template. The final-dot uniqueness stop occurred before the writer ran, so none of these planned output bytes exists for H61U.

What this does not establish

  • A gravity edge is non-unique: a finite intrabasement density sheet, intrusive contact, or pluton margin can mimic a basement step.
  • The inverted depth is not GP-1012-calibrated. Absolute depths, throws, and predictions of private-test performance must not be described as calibrated.
  • The output's raster-level uniqueness is evaluated only over accessible aligned registry rasters. It does not prove no private submission is similar.
  • Withheld catalogue recovery is local HOLDOUT-DTI, not organizer leaderboard DTI.

Shared implementation

The run uses gems61.buried, shared holdout/fold tools, gems61.evaluate_holdout, and the strict pre-placement/final uniqueness gate. The shared submission writer is invoked only after uniqueness passes; it was not reached in this run. A shared signed-flank mask defect found in the invalid first attempt was repaired in place and regression-tested before the unchanged retry. See the review record and source/access status.

Frozen H61U-H1 parameters and provenance are recorded in the run card and preregistration data.
