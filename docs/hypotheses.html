#5 H61-K — Scale-persistent paired-flank basement-step ribbons with magnetic corroboration

LayersSupplied isostatic gravity → provisional inverted basement depth and its horizontal gradients at 200/400/800 m; supplied TMI/tilt/vertical-gradient magnetic bands as corroboration only. GP-1012 calibrates the regional depth scale.
Physical signatureA candidate step has paired cross-profile gradient flanks of opposite sign, coherent strike, and a persistent location across scales; a co-located magnetic edge supports but is not required for the ribbon.
Why it may catch catalogue-missing faultsBuried basin-interior faults can be omitted or fragmented in the mapped catalogue. Pairing, strike continuity, and scale persistence may suppress isolated density contacts/noise while allowing multi-line fault ribbons under alluvium; magnetics provide an independent but imperfect corroborating signature.
Difference from implemented workDistinct from H61-MH, which used supplied bands and inversion-derived variables in a learned habitat model, and from H61-H, which proposed simple gravity/magnetic edge conjunction. This untested rule matches paired flank geometry and scale persistence before ribbon emission; it uses no catalogue-derived candidate features.
Expected DTI gain (projection, not score)Low-to-moderate expected gain, PROJECTION ONLY: paired-flank geometry may improve precision, while requiring magnetic corroboration can lose faults without magnetised offsets. No measured DTI.
Cost / dataMedium-high: compute multi-scale derivatives, orientation-aware cross-profile pairs, and pre-placement registry gates; run one holdout only if the surface first clears.

Selection rule

A hypothesis may proceed to holdout only after its pre-placement surface passes the declared-uniqueness gate against every raster in the declared inventory: signed Spearman ≤ 0.90, one-sided 3 px overlap ≤ 70 %, with the Jaccard exception (IR-61-UNIQ-01) waived only where the comparator is itself a near-blanket. A passing surface would then be tested by the shared spatially blocked hide-and-recover evaluator, with a feature-alone leakage canary and a matched random-line control. Weekly promotion is a separate selector decision. The current-run H61-L candidate failed before holdout, so no score or TIFF is imputed for that run. A separate archived main-branch H61-L TIFF is retained as historical, and fails the strict final-dot gate.
