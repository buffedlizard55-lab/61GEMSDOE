H61U-H1 stopped at final-dot uniqueness. This page records the fixed physical hypothesis and protocol; it does not describe a downloadable artifact.

Gravity inversion

Only band 13, the isostatic gravity anomaly, enters the inversion. The fixed 400 m grid, z0=1000 m, density contrast −400 kg/m³, and order-2 stabilizing filter define an uncalibrated prior. H61U uses the first low-pass Bouguer-slab iterate from the shared Parker–Oldenburg formulation; it does not run later nonlinear correction iterations. No priors were tuned against withheld labels.

Step signature and ribbons

Horizontal-gradient maxima on the inverted basement-depth surface define candidate crests. Signed depth offsets are sampled across each local normal at 2 km and 4 km; both must have the same polarity and their magnitude ratio must be at least 0.60. The frozen emission rule is a 3-pixel ribbon under a 40,000-pixel budget. The code did not emit any H61U TIFF because the final-dot gate failed.

Calibration boundary

The complete official GP-1012/NOAA-NCEI depth grid is not locally available and a documented registration to the competition grid is unresolved. No depth-scale calibration is claimed. The contest's band 15 is prohibited as a calibration target/reference and as a prediction feature; literature quantiles are not substituted.

Competing explanation

A finite mafic/granitic density body or intrusive contact within basement can generate gravity edges without basement relief or a fault. The registered synthetic density-sheet mechanism control had zero basement relief and tested the same sign-persistence filter; it was not assigned a DTI score because it had no fault truth. One control geometry does not cover all source types.
