What would unblock a new candidate

  1. Start from a new in-lane hypothesis and build a pre-placement surface from permitted geological inputs.
  2. Compare that surface against every raster in the declared accessible inventory; stop if positive Spearman >0.90 or if more than 70% of positive pixels are within 3 px of any single prior raster (the Jaccard exception waives that leg only for a near-blanket comparator, and drift into another lane still stops the run).
  3. Only after a passing surface, run the shared spatially blocked hide-and-recover evaluator, visible-only catalogue features, pixel-exact masking, the feature-alone leakage canary, and a matched random-line control.
  4. Write ribbons, check the final raster with the same strict gate, validate with the shared writer, and promote only if the holdout selector says it beats the holdout best. A weekly slot remains separate.

Limitations

  • The current index covers 21 paths from scripts/registry_sources.tsv and 14 TIFFs across local roots (35 records); it is not the organizer-side registry. The original H61-G/H61-L run receipts retain their 21+7 pre-merge snapshot.
  • All 12 locally published candidate TIFFs exceed the literal final-dot overlap stop against the hash-pinned HGM prior. The archived main-branch "UNIQUE" labels are retired; see the measured audit. This short-circuit final-dot audit does not supply missing pre-placement receipts.
  • The current-run H61-L 3DEP-derived descriptor source is a public repository derivative. Its surface was not holdout-scored. Archived H61-L and H61-MH variants have HOLDOUT-DTI proxy values, but their final TIFFs fail the strict final-dot gate; H61-MH is 99.6400% one-sided overlap.
  • The production basement surface is a first low-pass slab iterate; a converged nonlinear Parker–Oldenburg inversion remains unverified.
  • HOLDOUT-DTI uses mapped catalogue segments as proxy truth, while competition truth is undisclosed/unmapped. No HOLDOUT-DTI value is a live score.
  • Score claims for H33/H19 are owner-reported in the available forensics; no receipt binding exact artifact bytes to a score was found.
