Known scientific and evaluation limitations

  • The inversion prior's absolute depth scale is uncalibrated until GP-1012 is obtained and registered. H61U's same-sign persistence is intended to be scale-invariant, but the final geophysical depth/throw values are not calibrated.
  • The available catalogue is a proxy. Whole-component hide-and-recover tests do not reveal performance on the organizer's undisclosed, newly identified faults.
  • Basement-depth HGM maxima are not uniquely faulted. The finite density-sheet control tests one named non-fault mechanism, not all intrusive contacts, plutons, alteration zones, or source depths.
  • The public registry contains only accessible aligned rasters. A pass does not prove uniqueness against private or inaccessible submissions.
  • The public leaderboard exposes account-best rows, not TIFF identity. H33-2-B2's reported 0.2778 attribution remains unverified.
