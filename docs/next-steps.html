What is still blocking a top-of-leaderboard score

  1. No locator generalises across space. All four locators tested sit at 0.02–0.05 LOQO-DTI and 0.56–0.59 blocked canary AUC. Until that changes, no file from this lane can be expected to beat 0.2778.
  2. Metre-scale topography is the named obtainable source. USGS 3DEP 1 m DEM tiles over the high-prior zones (free public domain from USGS The National Map, apps.nationalmap.gov/downloader). The sandbox egress allow-list blocks prd-tnm.s3.amazonaws.com and usgs.gov, so the tiles must be fetched on an unrestricted machine and mirrored into a GitHub repository that scripts/prepare_data.py can pin by sha256 — exactly the pattern already used for the feature stack.
  3. The hidden truth is not observable. The public labels.tif is byte-identical to existing_faults.tif (the mapped catalogue), so every number we produce is a hide-and-recover index on catalogue traces, not a score. The single highest-value action is to record one ORGANIZER-CONFIRMED score for a lane file so the proxy can be calibrated against the real metric.
  4. Weekly submission slots are capped (see the submission page). Promotion of any file is a separate selector step; this session's card records a negative verdict and does not spend a slot.

Limitations of this session's evidence

  • The group's own scores are owner reports (IR-61-SCORE-01); the public leaderboard belongs to other teams.
  • The holdout withholds catalogue segments, which are adjacent to visible traces by construction; the leave-one-quadrant-out test is the correction, and it is harsher than the live problem in one respect (it removes all faults from a quadrant).
  • The habitat model's negatives are random footprint pixels, so the model learns "fault-like habitat", not "fault absent from the catalogue".
