What is measured about the H33 bytes

The group-reported value is 0.2778, attached to gemsdoe32-h33-h33-2-b2-20261004T220000Z-e5eb6e7e-zeros.tif with SHA-256 c55bafc470054e8271dcb89347a17e07fefe50de6af6e6ba6c4b169ef7ab6fa9. Byte-level forensics finds that raster is a strict subset of the 44,090-pixel h19-5 core: 44,090 core pixels → 37,654; 6,436 removed pixels are all within 3 px of the mapped catalogue. This is a measured construction relationship, not proof of the claimed leaderboard score.

The plausible metric mechanism, conditional on the report being accurate, is geometric: DTI uses a 300 m triangular kernel with α=.2 and β=.8; pruning positives beside already-mapped faults removes guaranteed/near-guaranteed false positives. The measured set difference supports that explanation, but without a submission receipt we cannot assert the artifact scored 0.2778.
